# 合成与交付核对

在取得插画以及导出 PNG 后使用。

1. **核对原图。** 确认人眼看到的方向与原文件一致，全部四角与场布可见。默认路径用输出 JSON 的 `photo_box` 裁下 PNG 区域，与原图经 `ImageOps.exif_transpose(...).convert("RGB")` 后的尺寸和 RGB 像素逐一比较。有 ICC 时检查输出是否沿用原图的 RGB ICC。用户授权缩小时，与按报告尺寸 LANCZOS 等比缩小后的像素比较。
2. **对照插画。** 看主景结构、机位、走道和花艺的关键位置是否匹配，可见环境线索是否正确。检查插画边缘和纸面自然相接，主体完整，绘画里没有模型误写的招牌文字。先修正插画，再运行同一排版命令。
3. **读回标题。** 逐字检查，确保只有一行，能在共用区完整阅读。字体缺字时选覆盖整行的 `--font`，标题过长时按用户意象缩短或采用更宽画布。
4. **确认交付。** 打开输出文件。报告实际画布尺寸与原图是否缩小；交付最终 PNG，按用户需求保留此次使用的插画及提示词供复作。只有提示词或手工规格时，说明还缺哪个阶段。

| 脚本反馈 | 处理方法 |
| --- | --- |
| 原图有透明像素、颜色模式或 ICC 不可读 | 请用户提供同一图的 8 位不透明 sRGB 导出，或使用可读取的 RGB ICC。 |
| 插画边缘过暗或底色不均 | 用原图重新取得透明 PNG 或近白均匀底插画，留出四边。 |
| 画布过小或自动尺寸超出上限 | 使用可容纳的原尺寸画布。用户接受缩小时传 `--size` 和 `--photo-fit contain`。 |
| 输出路径已存在 | 选新路径。确认替换这张成品时使用 `--overwrite`。 |
| 输出路径被锁定 | 等待同一路径的运行完成。进程已终止且空锁目录仍在时，清理对应 `.文件名.lock` 后重试。 |

复验确定性时，在相同 Python/Pillow 构建、字体和参数下，分别导出两次并比较 SHA-256。跨平台复验时检查图框坐标、原图区域与可见成品，记录所用解码、字体渲染和 PNG 库版本。
